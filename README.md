# ARTC для macOS

**[Скачать ARTC 0.9.5 — DMG для Apple Silicon](https://github.com/georJiks/ARTC-Releases/releases/download/v0.9.5/ARTC-0.9.5-osx-arm64.dmg)**

[Описание релиза и контрольная сумма](https://github.com/georJiks/ARTC-Releases/releases/tag/v0.9.5) · [Все релизы](https://github.com/georJiks/ARTC-Releases/releases)

Требуется macOS 13.0 или новее и Mac на Apple Silicon (M1 и новее). .NET встроен в приложение.

Откройте DMG и перенесите ARTC в Applications. Приложение и образ подписаны Developer ID и нотарифицированы Apple.

Для трансляции своего экрана разрешите запись экрана, для управления этим Mac — универсальный доступ в настройках macOS.

Этот публичный репозиторий предназначен для готовых сборок. Исходники приложения здесь не публикуются. Подробности проверок и ограничения указаны в описании релиза.
